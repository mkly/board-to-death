# Agent Guidelines

## Commit Message Policy
- Do NOT add AI, assistant, or tool attribution to git commit messages (e.g., do not include "Co-authored-by", "Generated by AI", "Created with Antigravity", or similar footers).
- Keep all git commit messages clean, concise, imperative, and professional.

## Shared Development Image

`distrobuilder.yml` defines the `board-to-death` Incus image: Ubuntu 24.04
(noble) with Git, build-essential, a pinned Node.js 24 LTS (bundled npm), and
a local PostgreSQL 16 server preinstalled so the application and its
Prisma-backed persistence layer can be imported, installed, built, and tested
without production credentials.

The PostgreSQL server is provisioned at boot by
`board-to-death-pg-bootstrap.service`, which pins the cluster to port 5432 and
creates a `board_to_death` superuser role (password `board_to_death`) with
`board_to_death` and `board_to_death_test` databases.

Build, smoke-test, and (re)publish the local `board-to-death` alias with:

```sh
./scripts/bootstrap-image.sh
```

Run it as your normal Incus user; it uses `sudo` only for `distrobuilder`,
which requires root and does not run inside a container. The previous image
is kept under a dated `board-to-death-prev-*` alias for rollback.

Once imported, warm a box against it with `INCUS_IMAGE=board-to-death`.
