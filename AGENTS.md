# Agent Guidelines

## Browser Development
- Use the `agent-browser` skill for any browser work: navigating pages, clicking, filling forms, taking screenshots, extracting data, and testing or dogfooding the app in a real browser.
- Prefer `agent-browser` over any other browser automation or web-fetching tool.
- Verify UI changes in the browser with `agent-browser` before calling them done; don't rely on tests alone.

## Commit Message Policy
- Do NOT add AI, assistant, or tool attribution to git commit messages (e.g., do not include "Co-authored-by", "Generated by AI", "Created with Antigravity", or similar footers).
- Keep all git commit messages clean, concise, imperative, and professional.
